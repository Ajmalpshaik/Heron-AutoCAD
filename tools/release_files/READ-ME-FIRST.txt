Heron AI for AutoCAD
====================

NOT FINISHED. The plug-in has not passed its live checks in every AutoCAD version yet.
Use it for testing only, and only on drawings you can afford to undo.

You need
  - Windows 64-bit and full AutoCAD 2021 to 2027 (not AutoCAD LT)
  - Claude Code or Claude Desktop, signed in
You do NOT need Python, the .NET SDK or an administrator password.

Install
  (Prefer one file? HeronAutoCAD-<version>-setup.exe on the same release page does the same
  and is removed from Windows Settings > Apps. Use one or the other.)
  1. Close AutoCAD.
  2. Double-click Install.bat.
  3. Restart Claude Desktop if you use it.
  4. Start AutoCAD. On the Heron tab press Heron to connect.
     Everything starts locked: press Settings and turn Changes on before Claude may draw.

What it changes (your Windows user only)
  - %APPDATA%\Autodesk\ApplicationPlugins\HeronAutoCAD.bundle   (the plug-in)
  - %LOCALAPPDATA%\Heron\autocad\autocad-mcp.exe                 (the server)
  - the Claude Code and Claude Desktop settings get one "autocad" entry, also when Claude is
    only the Claude app. An "autocad" entry already there is kept as it is, and each
    settings file is saved first as <name>.heron-backup. While the Claude app is open its
    own settings file is not changed: quit it and run this again.
  No registry, no services, no firewall rules, no network ports.

Update, go back, look for a newer one
  - A newer zip: close AutoCAD, run its Install.bat. The version it replaces is kept.
  - Trouble with the new one? Close AutoCAD and double-click Rollback.bat: it puts the
    earlier version back, after asking.
  - CheckForUpdate.bat says whether a newer version is out. It never installs anything.

capabilities.json
  The list of Heron's tools, with the padlock each needs and whether it has passed its
  live check, for other programs such as Heron AI for Revit. Nothing reads it today.

Remove it
  Close AutoCAD, then double-click Uninstall.bat. It shows what it removes and asks
  before removing anything. Keep this folder so Uninstall.bat is at hand.

Heron is not code-signed (Ajmal's decision). Windows SmartScreen or company antivirus may
warn about autocad-mcp.exe: if your IT team blocks it, ask them to allow that file. The first
time AutoCAD loads Heron it may ask whether to load it: choose to load it always, once.
