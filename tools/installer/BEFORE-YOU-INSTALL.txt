Heron AI for AutoCAD
====================

NOT FINISHED. The plug-in has not passed its live checks in every AutoCAD version yet.
Use it for testing only, and only on drawings you can afford to undo.

You need
  - Windows 64-bit and full AutoCAD 2021 to 2027 (not AutoCAD LT)
  - Claude Code or Claude Desktop, signed in
You do NOT need Python, the .NET SDK or an administrator password.

Before you press Next
  Close AutoCAD. Quit Claude Desktop (right-click its icon by the clock, Quit) and close
  Claude Code. This setup stops by itself, and changes nothing, while AutoCAD is open.

What it changes (your Windows user only)
  - %APPDATA%\Autodesk\ApplicationPlugins\HeronAutoCAD.bundle   (the plug-in)
  - %LOCALAPPDATA%\Heron\autocad\autocad-mcp.exe                 (the server)
  - the Claude Code and Claude Desktop settings get one "autocad" entry, also when Claude is
    only the Claude app. An "autocad" entry already there is kept as it is, and each
    settings file is saved first as <name>.heron-backup. While the Claude app is open its
    own settings file is not changed: quit it and run this again.
  No registry beyond Windows' own list of installed apps, no services, no firewall
  rules, no network ports.

Update, go back, remove
  - A newer version: close AutoCAD, run the newer setup. It replaces this one.
  - Going back: run the older setup from the Heron releases page on GitHub.
  - Start menu > Heron AI for AutoCAD > Check for a newer Heron: says whether one is
    out. It never installs anything.
  - Remove: Windows Settings > Apps > Heron AI for AutoCAD > Uninstall. Your saved
    commands, check lists and logs in %LOCALAPPDATA%\Heron\autocad stay.

Heron is not code-signed (Ajmal's decision). So, once:
  - Windows SmartScreen may say "Windows protected your PC": choose More info, then Run
    anyway. If your IT team's antivirus blocks the files, ask them to allow them.
  - The first time AutoCAD loads Heron it may ask whether to load it: choose to load it
    always, so it does not ask again.
